разница между режимами агента в Kilo:
`mode: primary` — агент появляется в переключателе сверху, я выбираю его руками и общаюсь с ним напрямую.
`mode: subagent` — в переключателе его нет, вызываю из другой сессии через `@имя` (например, `@scout`), он работает фоном и возвращает результат.
полезно для разделения: основной помощник — `primary`, а узкие ровые агенты (scout, planner) — `subagent`, чтобы не мешать друг другу в одном чате.
